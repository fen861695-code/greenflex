## 一、GreenFlex 是什么

GreenFlex 是一个 **AI 模型绿色路由平台**。你用自然语言描述任务（比如"帮我把这些评论分一下好评差评"），系统自动完成三件事：

1. **识别任务类型** — 判断你要做分类、摘要、写代码、翻译还是分析
2. **推荐最合适的模型** — 从 35 个模型中选出质量够用、价格最低、能耗最省的那个
3. **估算成本和碳排放** — 给出费用（元）、能耗（Wh）、碳排（g CO₂），并展示备选方案对比

**解决的核心问题**：不同 AI 模型价格差 100 倍、能耗差 10 倍，但大多数人不知道该选哪个。GreenFlex 帮你自动选，避免"杀鸡用牛刀"（用 GPT-4 做二分类）或"小牛拉大车"（用小模型写复杂代码）。

## 二、快速启动

### 环境要求
- Python 3.11+
- Node.js 18+
- 无需 GPU、无需安装 Ollama（默认模拟模式）

### 启动步骤

```powershell
# 1. 启动后端（端口 8000）
cd D:\GreenFlex\backend
$env:PYTHONPATH="src"
.\.venv\Scripts\python.exe -m uvicorn greenflex.api:app --host 127.0.0.1 --port 8000

# 2. 启动前端（端口 5173）
cd D:\GreenFlex\apps\web
npx vite --host 127.0.0.1 --port 5173

# 3. 浏览器打开
# http://127.0.0.1:5173
```

启动后看到绿色侧边栏即成功。左下角显示"本地模式"表示当前使用模拟推理，不消耗真实 API 额度。

## 三、六大功能入口

### 1. 工作台（首页 /）

**功能**：输入自然语言任务，获取智能推荐。

**使用方式**：
- 在输入框描述你的任务（不需要说 token 数、模型名）
- 选择路由模式：智能推荐 / 经济优先 / 质量优先 / 手动选择
- 点击"获取推荐"

**返回内容**：
- 识别的任务类型和复杂度
- 推荐模型、费用、能耗、碳排
- 5-29 个备选模型对比
- 推荐理由（为什么选这个模型）

### 2. AI 对话（/chat）

**功能**：选择一个模型，直接对话。

**使用方式**：
- 顶部下拉选择模型
- 输入消息，Enter 发送
- 支持多轮对话上下文

**当前状态**：默认模拟模式，返回占位文本（标注 `[模拟输出]`），但 token 数、延迟、费用、能耗按真实模型参数计算。配置云 API Key 后可真实调用。

### 3. 模型试跑（/preview）

**功能**：同一段文本发给多个模型，横向对比延迟、能耗、能效。

**使用方式**：
- 输入测试文本
- 勾选要对比的模型（可多选）
- 点击"运行"

**返回内容**：每个模型的延迟（ms）、GPU 能耗（Wh）、每 token 焦耳数。

### 4. 批量下单（/orders/new）

**功能**：批量提交任务，获取报价后下单。支持碳地图查看各区域碳强度。

### 5. 订单列表（/orders）

**功能**：查看历史订单、状态、费用和能耗。

### 6. 设置（/settings）

**功能**：配置云服务商 API Key。支持 6 家：OpenAI、Anthropic、DeepSeek、阿里通义、字节豆包、Google Gemini。

**安全说明**：
- 修改设置需要管理员令牌（`backend/artifacts/admin_token.txt`）
- API Key 仅存储在本地 SQLite 数据库，不上传第三方
- 未配置 Key 时调用云端模型返回友好错误

## 四、核心机制：任务分类器怎么选模型

### 4.1 七种任务类型

| 任务类型 | 触发词示例 | 默认档位 |
|---------|-----------|---------|
| 分类判断 | 分类、判断、识别、区分、筛选、情感分析 | economy ~ balanced |
| 信息抽取 | 提取、抽取、找出、解析、列出 | economy ~ quality |
| 摘要总结 | 总结、摘要、概括、提炼、归纳、梳理 | balanced ~ quality |
| 内容生成 | 写一篇、撰写、起草、生成文案 | balanced ~ enterprise |
| 分析推理 | 分析、评估、对比、诊断、原因 | balanced ~ enterprise |
| 代码编程 | 用Python写、实现、调试、SQL查询 | quality ~ enterprise |
| 翻译 | 翻译成、中译英、英译中 | economy ~ balanced |
| 通用任务 | 你好、在吗、帮我弄一下 | balanced（低置信度） |

### 4.2 四个模型档位

| 档位 | 适用场景 | 代表模型 | 参考价格 |
|------|---------|---------|---------|
| economy | 二分类、简单抽取、短翻译 | GPT-4o Mini、Gemma 3 1B | ¥0.1-0.3/百万token |
| balanced | 摘要、通用生成、中等分析 | 通义千问 Turbo、Gemini Flash | ¥0.3-2/百万token |
| quality | 代码、深度分析、长文写作 | DeepSeek-V3、Gemma 3 4B | ¥1-4/百万token |
| enterprise | 董事会汇报、核心业务、法律医疗 | 豆包 Pro 1.5、GPT-4o | ¥10-60/百万token |

### 4.3 自动升档规则

分类器会根据自然语言暗示自动提升档位：

- **数量暗示**："500 条"→复杂档，"几十条"→中等
- **长度暗示**："详细"、"深度"→长输出→升档
- **质量暗示**："给老板汇报"、"不能出错"、"董事会"→高质量→升档
- **难度暗示**："架构瓶颈"、"根本原因"、"安全漏洞"→升档
- **多意图**："提取后翻译"→多任务→升档

## 十、常见问题

**Q：为什么 AI 对话返回的是"[模拟输出]"？**
A：默认模拟模式不连接真实模型。返回的文字是占位符，但费用/能耗/延迟按真实模型参数计算。配置 API Key 后自动切换为真实调用。

**Q：推荐的模型一定是最好的吗？**
A：是"在你任务场景下综合最优"的。系统在质量底线之上优先选价格低、能耗低的模型。如果你要求最高质量，可以在工作台切换到"质量优先"模式。

**Q：碳排放数据准确吗？**
A：碳排 = 能耗 × 所在区域电网碳强度。能耗基于模型参数和官方基准估算，碳强度来自国家能源局公开数据。是工程估算值，不是精确计量值。

**Q：模糊输入（如"帮我弄一下"）会怎样？**
A：系统标记为"通用任务"，置信度"低"，推荐均衡档模型，并提示用户补充需求。不会强行猜测任务类型。

**Q：API Key 安全吗？**
A：Key 仅存储在本地 SQLite，修改设置需要管理员令牌，所有写入接口有鉴权。不会上传到任何第三方。
