# ADR 0005: GreenRouter 智能模型路由规则 v1

- 状态：Accepted
- 日期：2026-08-06
- 决策者：GreenFlex 团队

## 背景

GreenFlex v0.1 提供了三档固定模型（经济/标准/高质量），用户需要手动选择。
基于三轮共 1092 次真实推理实验，我们发现：

1. **不同任务对模型能力的需求差异巨大**：简单分类/抽取任务用 0.5B 即可完成，
   而代码生成、复杂分析必须使用 3B 模型。
2. **固定档位导致能耗浪费**：Router-v2 实验显示，智能路由可降低 GPU 能耗 22.8%
   （95% CI 18.8%-26.5%），但 F1 下降 4.4 个百分点，质量非劣性检验未通过。
3. **用户需要可解释、可覆盖的推荐**：不能黑盒自动降级，必须展示理由、允许手动覆盖。

## 决策

实现 **GreenRouter Rule v1**——一个基于规则的两阶段推荐器：

### 阶段一：硬约束过滤（按顺序）

1. **可用性约束**：`enabled = true` 且运行时可用
2. **上下文长度**：输入 + 输出 ≤ 模型 `context_limit`
3. **截止时间**：执行时间 + 排队时间 ≤ 剩余时间
4. **预算约束**：预估价格 ≤ 用户预算
5. **质量下限**：
   - `critical`：仅允许 3B（quality 档）
   - `high`：允许 1.5B+3B
   - `standard`/`minimum`：允许所有
6. **任务能力**：代码/复杂推理排除 0.5B；简单分类/抽取允许所有

### 阶段二：多目标加权排序

综合评分（越低越好）：

| 维度 | 权重 | 说明 |
|------|------|------|
| 质量风险 | 0.35 | 任务-档位匹配风险 |
| 价格 | 0.20 | 预估推理费用 |
| GPU 能耗 | 0.15 | 预估增量能耗 |
| 碳排放 | 0.10 | 基于当前电网碳强度 |
| 执行延迟 | 0.10 | 预估推理时间 |
| 排队等待 | 0.05 | 队列深度估算 |
| 绿电奖励 | -0.05 | 高绿电时段降权 |

### 安全护栏

1. **高风险 + 低置信度 → 强制 3B**：不拿质量冒险
2. **置信度 < 50% → 不自动降级**：宁可保守
3. **0.5B 仅在 economy 模式 + 简单任务时推荐**
4. **候选分差 < 5% → 选更高质量**：避免为微小能耗牺牲质量
5. **影子模式默认开启**：推荐仅展示，不自动执行
6. **用户确认制**：必须用户点击"使用推荐"才会下单
7. **完整审计**：所有推荐决策记录到 `recommendation_decisions` 表

### 四种用户模式

| 模式 | 行为 |
|------|------|
| `smart` | 自动平衡质量、成本、能耗（默认） |
| `economy` | 优先低成本、低能耗 |
| `quality` | 优先输出质量 |
| `manual` | 用户手动选择档位/模型（原有行为） |

## 数据来源更新

基于公开文献更新了模拟参数：

- **GPU 能耗**：arXiv 2608.00008（RTX 4060 Ti, Qwen2.5 Q4）
  - 3B: 1.252 J/输出Token ≈ 0.348 Wh/千Token
  - 0.5B: 0.215 J/输出Token ≈ 0.060 Wh/千Token
- **电价**：2026 年华东工业分时电价（尖峰/高峰/平段/低谷/深谷）
- **碳强度**：华东电网 2023 年 0.55 kgCO₂/kWh（生态环境部）

## 后果

### 正面

- 用户无需理解模型参数即可获得合理推荐
- 简单任务自动路由到小模型，降低能耗和成本
- 所有决策可解释、可审计、可覆盖
- 为未来 v2（基于真实质量画像的 ML 路由）预留接口

### 负面

- 规则需要持续维护，新模型/新任务类型需要更新规则
- 当前质量风险矩阵基于先验知识，缺少真实任务质量数据
- 影子模式下用户需多一次点击确认

### 风险缓解

- `model_task_profiles` 表预留位置，未来可存储真实质量画像
- 推荐策略通过端口抽象，v2 可替换为 ML 模型而不影响上层
- 所有推荐记录可用于后续离线分析和规则调优

## 相关表

- `model_task_profiles`：模型-任务类型质量画像（v2 使用，当前为空）
- `recommendation_decisions`：推荐决策审计记录（不存储原始提示词）
