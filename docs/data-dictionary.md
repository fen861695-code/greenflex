# Data Dictionary

## Provenance

Every numeric environmental or commercial field carries one of:

- `measured`: observed locally from the inference runtime or hardware telemetry.
- `estimated`: derived from measured data using a declared factor or allocation rule.
- `simulated`: generated by a versioned digital-twin fixture.

## Canonical units

| Concept | Storage | API/display |
|---|---|---|
| Money | micro-RMB integer | RMB decimal |
| Energy | micro-Wh integer | Wh or kWh decimal |
| Carbon | micro-gCO2e integer | gCO2e decimal |
| Power | milliwatt integer | W decimal |
| Duration | microseconds integer | ms or seconds |
| Token count | integer | integer |

## Carbon reporting

Location-based emissions, market-based claims, and avoided emissions remain separate. v0.1.0 has no retired certificate inventory and therefore cannot make a market-based green-electricity claim.

## Privacy boundary

Prompts and outputs are operational content. They may exist in the local order store until purged, but never appear in logs, metrics, Passports, Git fixtures, screenshots, or public artifacts.
